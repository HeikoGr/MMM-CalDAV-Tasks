# Installation

## Requirements

- Node.js `>=20`
- A reachable CalDAV server such as Nextcloud Tasks
- Valid CalDAV credentials or an app password

## Install The Module

```bash
cd ~/MagicMirror/modules
git clone https://github.com/HeikoGr/MMM-CalDAV-Tasks
cd MMM-CalDAV-Tasks
npm install
```

After installation, continue with [Nextcloud Preparation](Nextcloud-Preparation) and then [Quick Start](Quick-Start).
